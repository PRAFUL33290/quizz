# Défi Numérique Junior

Jeu éducatif web pour enfants de 7 à 9 ans sur l’univers du numérique.

## Lancer le jeu

Ouvrir `/tmp/workspace/PRAFUL33290/quizz/index.html` dans un navigateur moderne.

## Fonctionnalités

- Quiz visuel et dynamique (écrans Accueil / Partie / Fin)
- Base générée automatiquement de **330 questions** (3 réponses, 1 correcte, difficulté Facile/Moyen/Difficile)
- Thèmes: Informatique, Internet, Sécurité numérique, Jeux vidéo, Culture numérique, Logique numérique
- Score + combo + bonus (x2, x3, bonus streak 5/10/15)
- Événements spéciaux: Question Éclair, Jackpot, Pixel Bonus, Mot de Passe, Défi Hacker Junior
- Grades: Explorateur → Génie Informatique
- Sons de réussite/erreur, confettis sur record, badges
